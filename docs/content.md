# Movistrato — Content & Claims

## 1. Company

**Movistrato** is a software product company.

It develops its own software products.

It is not presented as:

- a software development agency;
- a consulting business;
- a website studio;
- a freelance portfolio.

## 2. Product hierarchy

```text
MOVISTRATO
└── PRODUCT / 01
    └── FARO
```

Movistrato is the parent company.

FARO is the first product.

Do not imply that FARO is the entire company.

Do not invent Product 02, Product 03, etc.

## 3. FARO

FARO is a language-learning software product.

Core product direction:

- contextual learning;
- continuous exposure;
- adaptive experience;
- practice;
- progress;
- AI-assisted learning where it adds real value;
- multi-device strategy.

Do not define FARO merely as “a better Duolingo” or “TikTok for languages”.

Those comparisons may help explain an idea internally, but they are not the product identity.

## 4. Current/planned platform status

Current project truth to use unless explicitly updated:

### Current
- Web/browser
- Android
- Windows

### Planned / future
- Linux
- iOS
- macOS

Never present planned platforms as already available.

## 5. Technology claims

Do not claim:

- fully autonomous adaptive learning;
- proprietary algorithms already validated;
- enterprise-scale infrastructure;
- massive production load;
- scientific validation;

unless the repository/project documentation explicitly supports the claim.

For future work use terms such as:

- in development;
- planned;
- next phase;
- objective;
- proposed system.

## 6. Forbidden fabricated content

Never invent:

- customer count;
- revenue;
- downloads;
- users;
- testimonials;
- customers;
- partners;
- investors;
- awards;
- offices;
- employees/team members;
- press coverage;
- performance metrics;
- security certifications.

## 7. Tone

Movistrato should sound:

- precise;
- confident;
- intelligent;
- technically credible;
- human;
- restrained.

Avoid:

- “revolutionary”;
- “disruptive”;
- “world-class”;
- “game-changing”;
- “cutting-edge”;
- empty “innovation” language.

Show ambition through the quality of the product and reasoning.

## 8. Portuguese

Portuguese must be **Portuguese from Portugal**.

Use:

- utilizador;
- aplicação;
- telemóvel;
- ecrã;
- aprendizagem;
- ficheiro.

Do not use Brazilian Portuguese vocabulary.

## 9. English

English copy should be written naturally.

Do not translate Portuguese sentence-by-sentence if a more natural English formulation exists.

These are working copy, not immutable brand slogans.
