# Movistrato — Internationalisation

## 1. Library
Use **next-intl**.

## 2. Locales
- Portuguese (Portugal): `pt`
- English: `en`

## 3. URLs
```text
/pt
/en
/pt/products/faro
/en/products/faro
/pt/technology
/en/technology
/pt/company
/en/company
```

## 4. App Router
Locale routing belongs under `src/app/[locale]/`.

Use the current recommended `next-intl` integration for the installed Next.js version. Do not copy outdated middleware/proxy examples without checking versions.

## 5. Translation architecture
Avoid scattered:
```tsx
locale === "pt" ? "Empresa" : "Company"
```

Use central locale-aware messages/content.

## 6. Route-preserving switch
`/pt/company` should become `/en/company`, not `/en`.

## 7. Metadata
Localise title, description, canonical, alternates, OpenGraph locale and document language via Next.js metadata APIs.

## 8. Portuguese quality
Use Portuguese from Portugal: utilizador, aplicação, telemóvel, ecrã, aprendizagem, ficheiro.

## 9. English quality
Write natural English rather than translating mechanically.

## 10. Content
Keep complex content structured and replaceable without rewriting layout.
